The react-phone-number-input 3.4.18 patch reports input changes in the input event instead of a prop-synchronization effect, avoiding stale-value feedback loops in controlled intake fields. Both ESM and CommonJS builds are patched.

The @claritylabs-inc/ui 0.21.0 patch keeps dropdown submenus beside their parent, flips them horizontally when necessary, falls back vertically when neither side has enough space, and forwards anchor and collision settings to the Base UI positioner. Menus portal to the document body so inline dialog portals in resizable app panels cannot clip them. The submenu minimum width respects the available viewport width.
