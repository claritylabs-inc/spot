# PDF assets

`allura-regular.json` bundles the unmodified Allura Regular TTF as base64 so
Convex can render the cursive name placeholder without a network request or
runtime filesystem. Source: [Google Fonts Allura](https://github.com/google/fonts/tree/main/ofl/allura).
The font is licensed under the SIL Open Font License; see `Allura-OFL.txt`.
The displayed cursive name is a placeholder, independently of recorded checkbox acceptance.

`geist-regular.json` bundles the existing `app/fonts/geist/Geist-Regular.ttf`
for PDF body text, matching the reference document and Spot's app typography.
Its SIL Open Font License is included in `Geist-OFL.txt`.
