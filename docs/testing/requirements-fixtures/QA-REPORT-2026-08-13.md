## Defects found and fixed during the loop

- Semantic duplicates were previously vulnerable to title/line-level suppression. Deduplication now compares normalized typed limits, deductible, coverage form, retroactive date, provisions, and required forms.
- Imports could accept coverage rows with no checkable terms. They now require at least one typed limit, deductible, form, retroactive date, provision, or required form.
- Failed model extraction could leave a misleading completed source. Source persistence now occurs only after successful extraction; a successful zero-row duplicate import still records its audit source.
- DOCX parsing passed an unsupported ArrayBuffer option to Mammoth in Node. It now uses a Node `Buffer`, backed by the real fixture regression test.
- Generic display limits could be overread as typed per-claim/per-occurrence/aggregate evidence. They no longer prove typed terms.
- Missing deductible, coverage form, retroactive date, provision, and required-form evidence was not consistently treated as unresolved. Missing evidence is now `Unverified`; explicit mismatches remain `Not met`.
- Cyber could match the E&O coverage. Coverage aliases now resolve Cyber to Network Security & Privacy Liability.
- Deep review lacked a bounded model-call timeout and had an invalid status instruction. It now aborts after 75 seconds and emits only valid statuses.
- Router-backed object/text calls dropped abort signals. The shared model adapter now preserves them.
- Certificate preflight could omit saved review rationale and mishandle one-requirement/source arguments. It now carries the rationale and uses the correct exclusive backend contract.
- Requirement-backed certificate generation could appear available with no satisfied requirement. The action is disabled unless at least one selected requirement is `Met` or `Expiring soon`; agents receive the same rule.
- Source filtering grouped broad categories instead of selecting an actual source document. The filter now targets the exact source ID.
- Source/requirement archive actions lacked adequate destructive confirmation. Both now use destructive `PillButton` treatment and explicit cascade copy.
- Standalone Conductor Slack fixtures defaulted to port 8084 without `CONDUCTOR_PORT`. Port discovery now derives the six-port namespace from the native-local Convex config.
- Worktree-local URL environment values could drift. The web launcher now refreshes the current native-local URLs before starting Next.js.
- OTP labels were not reliably associated with the actual hidden input. The shared field now owns an ID, and every sign-in surface uses `htmlFor`/`id` pairs.
- Convex Auth's Next.js cookies were session-only despite a 30-day backend session. Cookie lifetime now matches the backend session.
- Customer chat rendered raw provider reasoning that could repeat hidden instructions. Public thread queries now remove it, and the activity UI shows only auditable tool steps.
- ESLint traversed generated `.context/convex-tmp` bundles. `.context/**` is now a global ESLint ignore, restoring a meaningful and fast lint gate.
- The original QA runbook described old checker limitations and statuses. It now matches the conservative evidence behavior verified here.

## Release notes and residual risk

- Live external email, SMS/iMessage, and production Slack transports were not invoked from the isolated local environment. They share the same grounded agent context and channel-neutral runner exercised by web chat and the signed local Slack fixture, while their worker builds and cross-channel tests pass.
- No production deployment, external message, or generated certificate was created as part of QA.
- The seeded policy intentionally lacks typed declaration evidence. `Unverified` is the correct release behavior until source-backed typed facts are present; this is not a failed compliance result.
