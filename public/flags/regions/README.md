US state and Canadian province/territory flags, 48x36 WebP (`<COUNTRY>-<CODE>.webp`), used by `components/ui/region-flag.tsx`.

Rendered from the public-domain SVGs in the `region-flags` npm package (sourced from Wikimedia Commons). Mississippi (2021), Minnesota (2024) and Utah (2024) come from the current Wikimedia Commons files because the package has superseded designs.
